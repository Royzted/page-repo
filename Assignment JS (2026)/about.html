About the Project

GameVault is a JavaScript-powered video game catalogue built for a Web Development assignment. It demonstrates dynamic DOM manipulation, Handlebars templating, localStorage persistence, and integration of the Swiper.js carousel plugin.

The site is structured across three pages: a Welcome page with interactive animations, a Collection page for full CRUD data management, and this About page with comments and expandable FAQs.

All data persists in the browser via localStorage, so your collection and comments survive page refreshes.

Frequently Asked Questions

How is the data stored?
All game data and comments are saved in the browser's localStorage. This means your data persists across page refreshes and browser restarts — but it is device-specific and not shared between browsers.
How does the search work?
The search box on the Collection page filters the games array in real time as you type. It matches your query against the title, genre, and developer fields (case-insensitive).
How does sorting work?
Choose a field (Title, Year, Rating, or Genre) from the dropdown, then click the A→Z button for ascending order or the Z→A button for descending. The grid re-renders instantly using JavaScript's built-in Array.sort().
Which third-party plugin is used?
Swiper.js (v11) powers the featured games carousel on the Home page. It is loaded via CDN and initialised with new Swiper(…) inside initFeaturedSwiper() in script.js. Features used: autoplay, pagination bullets, prev/next navigation, and responsive breakpoints.
How are game cards rendered?
Cards on the Collection page and comments on this page are both rendered using Handlebars.js. The templates are embedded in the HTML as <script type="text/x-handlebars-template"> tags. Handlebars.compile() converts them into a function that accepts the data array and returns HTML.
